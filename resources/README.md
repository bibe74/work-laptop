# Resources

This folder contains additional resources, templates, configuration files, and reference materials.

## Contents

### Configuration Files
- Sample configuration files for various tools
- Template project files
- Settings export files
- Connection string templates

### Templates
- SQL Server database project templates
- Power BI report templates
- SSIS package templates
- SSRS report templates
- Documentation templates

### Reference Materials
- Architecture diagrams
- Network configuration diagrams
- Standard naming conventions
- Code style guides
- Best practices documents

### Tool-Specific Resources
- Visual Studio snippets
- VS Code extensions list
- SSMS custom snippets
- Power BI custom themes
- DAX formula templates

## Security Note

⚠️ **Do NOT store sensitive information here**:
- Passwords or credentials
- API keys or tokens
- Client-specific data
- Connection strings with real credentials
- License keys

Use placeholders or reference external secure storage for sensitive data.

## File Formats

This folder may contain:
- `.json` - Configuration and settings files
- `.xml` - Config files, project templates
- `.sql` - SQL scripts and templates
- `.ps1` - PowerShell script snippets
- `.pbit` - Power BI template files
- `.txt` - Text-based references
- Image files for documentation
